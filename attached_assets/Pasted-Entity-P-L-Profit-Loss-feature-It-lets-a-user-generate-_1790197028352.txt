Entity P&L (Profit & Loss) feature. It lets a user generate a financial statement for one entity—or all entities—from an Enterprise Data cube they’re authorized to access.

What it allows
Create an Entity P&L Analysis board and select a cube, entity, and as-of month.
Compare quarter-end monthly results against the prior quarter (QoQ), or year-to-date results against the same month last year (YoY).
View results in USD or INR, optionally with a CF forecast scenario in a separate column from Actual.
Review revenue, expense lines, EBIT (revenue minus total expenses), EBIT%, and on-roll/outsourcing capacity, plus a chart, summary, and source-evidence notes.
Run the analysis again and download a PowerPoint financial-statement slide or a PDF summary.
Each run reads the authorized cube through the server; it does not copy the Enterprise Data rows into the board. The standalone board currently saves its settings and generated reports in the browser’s local storage, so those saved board reports are not a shared server-side report repository.
